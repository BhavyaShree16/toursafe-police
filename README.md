# 👮 TourSafe Police Dashboard

Real-time emergency monitoring and incident management dashboard for police authorities.

---

## Overview

The Police Dashboard provides authorities with a centralized interface to monitor SOS alerts, track tourist status, and coordinate emergency responses in real time.

---

## Features

- Live SOS alert monitoring
- Tourist information tracking
- District-based filtering
- Alert management workflow
- Real-time dashboard updates
- Incident status monitoring
- Location-aware emergency tracking

---

## Tech Stack

- React.js
- JavaScript
- Axios
- Socket.io Client
- CSS
